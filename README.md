# Valentine Web App

A playful, interactive web app that asks: "Will you be my Valentine?"

## Run locally with Docker

```bash
docker compose up --build
```

Open `http://localhost:8081`.

## Customize

- Replace gallery images in `assets/` with your real photos.
- Edit messages in `script.js` (reasons, date ideas, vibe text).
- Tweak the copy in `index.html` and styles in `styles.css`.
